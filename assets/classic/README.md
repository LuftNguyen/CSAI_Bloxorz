# Classic textures

Six original procedural PNG textures generated by
`scripts/generate_classic_assets.py` with fixed random seeds and Pillow.
No artwork was extracted from the reference game or screenshot.
The renderer uses Ursina's bundled VeraMono font.

`audio/` contains eleven original synthesized mono PCM WAV effects (22050 Hz,
16 bit). Regenerate with `python scripts/generate_classic_audio.py` (stdlib only).
These effects are generated locally, without recordings from the reference game.
